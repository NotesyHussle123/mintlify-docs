---
title: "Roles and what each can do"
description: "The four roles in a workspace, what each one can see and change, and how to change someone's role."
---

Everyone in a workspace has one role: owner, admin, manager or rep. The role decides which conversations they see and which screens they can open.

## The four roles

- **Owner.** Everything an admin can do, plus billing, plan changes and deleting the workspace. There is exactly one owner.
- **Admin.** The whole workspace: settings, members and teams, numbers, templates, workflows and integrations.
- **Manager.** Sees every conversation, assigns and reassigns them, sends broadcasts, and looks after the reps on their team.
- **Rep.** Works their own conversations and picks up unassigned ones. A rep does not see a teammate's conversations and has no access to workspace settings.

## What each role can do

| | Owner | Admin | Manager | Rep |
| --- | :---: | :---: | :---: | :---: |
| Reply in their own conversations and pick up unassigned ones | Yes | Yes | Yes | Yes |
| See every conversation | Yes | Yes | Yes | No |
| Assign a conversation to anyone | Yes | Yes | Yes | No |
| Delete a conversation (a rep archives instead) | Yes | Yes | Yes | No |
| Use saved replies | Yes | Yes | Yes | Yes |
| Add, edit and remove saved replies | Yes | Yes | Yes | No |
| See contacts and record an opt-out | Yes | Yes | Yes | No |
| Add, edit, tag, import, export, merge and erase contacts | Yes | Yes | No | No |
| See and send broadcasts | Yes | Yes | Yes | No |
| See analytics | Yes | Yes | Yes | No |
| See workflows and what they do | Yes | Yes | Yes | Yes |
| Build workflows and switch them on | Yes | Yes | No | No |
| Connect WhatsApp numbers and create templates | Yes | Yes | No | No |
| Set up website chat | Yes | Yes | No | No |
| Connect integrations | Yes | Yes | No | No |
| Change workspace settings | Yes | Yes | No | No |
| Invite and remove people, change roles, create teams | Yes | Yes | No | No |
| Add reps to, and remove reps from, their own team | Yes | Yes | Yes | No |
| See the audit log | Yes | Yes | No | No |
| See the referral page | Yes | Yes | No | No |
| See the plan, usage and invoices | Yes | Yes | No | No |
| Change the plan, seats or card, or cancel | Yes | No | No | No |
| Accept a new version of the legal documents | Yes | No | No | No |
| Transfer ownership or delete the workspace | Yes | No | No | No |

Analytics and the audit log also depend on your plan. See [Plans](/billing/plans).

## Change someone's role

<Note>Owners and admins only.</Note>

<Steps>
  <Step title="Open the person">
    Go to **Settings**, then **Users and teams**, and select the person in the **Members** list.
  </Step>
  <Step title="Pick the new role">
    Choose admin, manager or rep under **Role**. The change is saved straight away and recorded in the audit log.
  </Step>
</Steps>

A few rules apply:

- You cannot change your own role.
- Nobody can change the owner's role, and nobody can be made owner this way. Ownership moves only by transfer.
- Making someone an admin takes them off their team, because admins work across every team.

You can also make someone a manager or a rep from a team's page. See [Teams](/team/teams).

## Transfer ownership

<Note>Owner only.</Note>

Transferring ownership hands over billing and the right to delete the workspace. You become an admin. If receipts were going to your email address, they move to the new owner's address.

<Steps>
  <Step title="Open the new owner">
    Go to **Settings**, then **Users and teams**, and select the person who will take over.
  </Step>
  <Step title="Choose Transfer ownership">
    Under **Danger zone**, choose **Transfer ownership** and type their name to confirm.
  </Step>
  <Step title="Confirm">
    Choose **Make [name] the owner**. It takes effect immediately.
  </Step>
</Steps>
